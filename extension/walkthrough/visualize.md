## Watch your code run

Every method you can run gets two buttons above it:

- **▶ Visualize** plays your code one step at a time — the current line lights up in the editor, and every variable is shown as it changes.
- **Complexity** runs it at bigger and bigger inputs and explains how its time and memory grow.

The input comes from your code: paste LeetCode's example as a comment —

```
// Input: nums = [2,7,11,15], target = 9
// Output: [0,1]
```

— and it is used automatically, with your result checked against the expected output.
